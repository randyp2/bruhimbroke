# Professor sprites

Original user-supplied JPEGs are preserved. The main menu uses these transparent
PNG copies, prepared with the built-in image generation tool:

- `prof-happy-cutout.png` from `prof_happy.jpeg`
- `prof-sad-cutout.png` from `prof_sad.jpeg`
- `prof-questionable-cutout.png` from `prof_questionable.jpeg`

Prompt used for each expression (substituting its name):

> Use case: background-extraction. Asset type: Chrome extension professor character sprite. Input image 1 is the edit target. Remove ONLY the baked-in gray and white checkerboard background, replacing it with genuine transparent alpha. Preserve this exact cartoon professor's identity, {expression} facial expression, pose, hairstyle, suit, tie, colors, proportions and dark outlines. Do not redesign or add body parts. Keep the entire existing character visible with a small transparent margin; crop away excess empty background. No text, no halo, no shadows, no added lighting. Deliver one transparent PNG cutout suitable for a dark UI.

The spotlight is CSS. The dashboard selects the expression from logged monthly
shopping relative to the user's optional monthly income increase: happy below
50%, questionable from 50% to under 100%, sad at 100% or more. Without income or
with tracking off, the questionable sprite is a neutral fallback. Zero logged
spending with income set is happy.
These are comedic UI thresholds, not judgments about the user's financial health.

## Purchase reactions

The interruption uses these additional transparent PNG copies, prepared with the
built-in image generation tool. The supplied JPEGs are preserved:

- `good-purchase-cutout.png` from `good_purchase.jpeg`: projected share below 50%.
- `bad-purchase-cutout.png` from `bad_purchase.jpeg`: projected share at least 50%.
- `reconsider-cutout.png` from `reconsider.jpeg`: at least 50% after insisting.

Missing price, missing income, disabled tracking, or unavailable storage keeps the
original questionable sprite. Price edits re-evaluate the reaction even after
insisting. None of these previews record a purchase.
